# 使用、排错与维护

基础版1.1.5，作者：自游；本文件不构成响应时限、付费售后或游戏结果承诺。

## 新用户先看这里

普通玩家先读根目录 README.md：默认在 支持 Skill 的聊天助手中直接说问题，附已有文字或截图；计算输入由助手准备，不要求玩家写数据文件。使用方法不清楚时直接问“这个技能怎么用”。

想自己填表时，再完整解压并打开 preview/index.html。保存草稿后可以重开，导出可读说明；开始自己的决定时使用空白输入，演示数据不是你的角色或行情。网页只支持有界问句，不是完整聊天模型。

不要输入游戏密码、身份证、令牌或银行卡资料；本产品用不到。

自然语言Skill要通过支持本地Skill和脚本执行的宿主使用。可把完整父目录文件夹或父目录根层含SKILL.md的完整ZIP按宿主现行导入流程导入。界面名字和宿主权限可能变化，先看官方说明：
[跨 agent 接入](../references/agent-compatibility.md)

需要运行计算时，让聊天助手使用已有Python。若运行报错，保留原输入，按具体错误核对执行权限、Python环境与文件路径。

不能执行Python的宿主仍可用已支持的浏览器表单；六类核心入口已提供表单，辅助工具和单一档案仍依赖宿主。入口与可重开格式见references/feature-matrix.md。没有已安装Python时不要执行来历不明的安装命令。

## 常见问题

- 页面一直“载入”：确认完整解压，HTML旁JS文件未改名；使用支持BigInt的现代浏览器。受公司/宿主安全策略限制时停止，不绕过安全告警
- JSON导入失败：保留当前草稿；检查是否把结果报告误当输入、文件超过1MB、格式/重复字段/币种或报价日期不正确。错误不应悄悄清空表单
- Python说文件已存在：输出用了旧文件名。换一个新文件名，避免覆盖输入/上次结果
- 未知成本：不是0。补对应级别/费用/库存机会价；若只影响经济成本，现金结果仍应可用
- “没有证明可行”：检查预算预留、资格、前置、互斥、共享库存和待核实候选，不是宣布整个游戏无解
- 学校/流派结果与记忆冲突：先比版本、服制、分支、经脉和公告生效日期。新全服公告覆盖旧基础说明，测试公告不自动视为全服
- 工具与手算不符：核单颗与逐级累计、当前已有经验、买入前现金与卖出后净价、机会成本与沉没成本、门槛与实际消耗
- 普通修理显示技能不足：这只阻止人物自行普通修理。80武器0耐久可选择图标右下角“修理”的仙玉快捷入口，或已有适用已激活乾坤石；只用游戏币时可找玩家修理服务，普通修理仍需少于3失败。保留费用选择，10仙玉仅历史列价，免费仙玉不能用于快捷修理。当前摊位买方最后按钮未核，不用编造菜单补齐
- 场景显示不适合或有未覆盖段：先分宝宝当前等级、目标等级与人物等级。35不在蓬莱109–159获经验区间；固定行覆盖缺口不等于所有练法无解
- 场景表按玩家等级分档：不要把列名改成队长等级。混级队伍如何选档未核，即使提供人物等级也只匹配表内条件
- 已有免费带练却仍无总价格/时长：免费只说明带练费状态，不证明总费用为0；缺实际速度、经验和其他成本时保留未知，覆盖路线也不保证账号能到目标
- 三失败宠装珍珠仍显示未知：先查包版本和as_of。当前依据为2013-03-19全服明文允许；历史版本曾保留未知，应升级后用原输入重算，不能试消耗。时间服右键珍珠、切目标所在栏、选宠装；最后消费按钮不写死。三失败宠装乾坤石资格仍未知，见references/repair-route-evidence.md


## 回报问题只需这些

包版本与SHA256、Python或浏览器版本、使用的命令/页面、最小脱敏输入、实际结果、期望结果及依据。不要发账号凭据或无关角色身份。截图先遮盖聊天/账号。独立研究记录和真实玩家私有数据不随包分发。

## 单一档案的继续与恢复

完整计划优先保存dossier编译输出的JSON bundle；它包含可回读的源档案和结果。更改事实时让宿主从自然语言更新新来源、对应事实、版本号和当前快照，再用dossier.py重算。不要只改缓存结果，也不要自行跑旧侧文件里的固定报价算术。compiled表示函数执行成功，不保证价格或行动可行。

编译报告的引擎/规则文件哈希会随软件更新改变；更新技能后重新启动执行进程并重算，保留旧包/旧档案用于对照。输入结构、引用、单位或上下文不一致时应先修正，不绕过校验。过大的展开会被拒绝，请按明确目标拆小档案，不把部分输出叫全局最优。

## 项目已经执行时

共同预算勾选明确已完成的候选，并更新实际当前余额/库存；已完成的项目可满足前置与其目标，不再收费/耗料。仅仅上次被推荐不等于完成。已完成路线互斥或漏记已完成前置会拒绝，请按实际执行历史核对。网页三套养成表单同档保存但不自动同步成本；需实时依赖重算时让宿主使用单一dossier。

## 问题交接

先在首页检查被识别的值和短语，再带到表单明确应用。不要把“缺少经验/上限”默认为0。普通修炼不需要无关区服，预算缺少货币时不比较购买能力。带字段链接可能留浏览历史；新草稿支持旧v1迁移。详见references/question-intake.md。
