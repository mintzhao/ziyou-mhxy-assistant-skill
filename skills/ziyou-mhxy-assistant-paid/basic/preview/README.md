# 自游·梦幻助手（基础版）：离线决策工作台

完整中文表单，不需要懂 JSON。计算在浏览器内使用精确整数算术完成；无需 Python、Node、联网、账号或安装依赖。所有游戏机制边界沿用已有计算器，不新增未经验证的规则。

## 打开与选择

1. 完整解压技能包，保留整个 `preview` 文件夹，不要只复制 HTML
2. 用支持 BigInt 的现代桌面浏览器打开 `preview/index.html`
3. 首页可先写一句问题选路径，再选择六类核心任务：普通资源、自升 / 替换、装备取舍、完整宝石、混合修炼、共同预算
4. 自升 / 替换默认从空白开始；可主动载入有明确标记的合成演示。装备工作区保留原有演示与空白入口

入口：
- `index.html`：六类任务入口；链接本身无需JavaScript，有界字段解析与核对交接使用guide.js/intake.js
- `decision.html`：新增现金、自有材料机会成本、条件出售与成品临界价
- `equipment.html`：原有装备组合、目标最低成本、Pareto 取舍和高级加权工具
- `equipment.html#resources-section`：直接显示并展开普通修炼与宝石工具，资源草稿可重开
- `planning.html#gem_upgrade`：完整普通宝石采购、库存与同目标成品
- `planning.html#training_mix`：普通修炼与经验道具混合购买
- `planning.html#portfolio`：多个目标、共享库存、已完成项目与共同预算
- 全部网页 / Skill / 命令行边界和草稿格式见 `../references/feature-matrix.md`

本地经典脚本，无模块加载、CDN、外部字体、外部图片或自动网络请求。页面 CSP 禁止网络连接。所需资源全部包含在目录中。报价来源仅保留文字，不自动打开链接。若页面未加载，按页面提示检查文件是否齐全与浏览器是否支持 BigInt。

## 自升 / 替换：不写 JSON 的完整流程

1. 写共同目标、区服与统一货币。比较基准日默认今天，可展开改；报价有效天数是人工核价窗口，不是价格保证。打开历史日期的真实草稿会醒目提示，可主动改为今天重算；原报价观察日期不自动改变
2. A 路线先填材料合计。合计按一份；需要拆分时添加行，展开名称与数量
3. B 路线填一个具体成品报价。有价格就补来源、观察日期、类型及报价区服 / 货币。录入金额时仅把当前区服与货币复制到空报价字段；改比较区服不会自动重标旧报价
4. 展开费用与自有材料。未知保持未知；确认没有时明确选择“我确认没有”。历史买入成本不应再次写进机会成本
5. 旧物未知或暂不出售时，净成本不下结论。条件出售仍不抵购入前备款；选择已结算必须提供成交类型的记录
6. 核对两条路线资格并能达到同一目标。没确认仍可做费用算术，但会明确警告不能据此推荐路线
7. 点击比较，看新增现金、机会成本、购入前备款、卖出后条件净成本，以及现金 / 经济口径可能相反的结果
8. “保存草稿”保存全部表单、报价依据、演示标记、未知值与备注；以后“打开草稿”可完整恢复并重新计算。尚未填完或待修正的数据也可保存
9. “导出决策说明 .txt”生成可读结论与报价清单；“导出计算输入与结果”生成可核对的计算包。结果包不是可编辑草稿，请同时保留草稿

合成演示的作用：新增现金 820.25、计入自有材料后 940.25；替换购入前要备 1280.75，只有条件卖出成立后净成本为 900.75。现金与经济口径方向相反，正好说明为何不能混成一个数字。所有示例均为构造数字，禁止当作真实市价。

### 草稿与隐私

不自动持久保存。关闭页面前手动保存；修改后离开会提示。导入有 1 MB 上限、严格结构和重复字段检查。读文件期间有新编辑时不覆盖；损坏文件不会替换当前数据。下载文件含你填写的来源与备注，发给别人前自行检查。

金额为普通非负十进制文本，最多 6 位小数、单项最大 1,000,000,000,000。数量乘单价的结果可精确保留 12 位小数。没有货币换算、市场预测、实战等价推导或自动购买。

## 装备方案取舍：一次真实比较怎么做

### 1. 角色与当前面板

- 填比较名称、预算与统一货币单位
- 角色等级、门派、区服与用途可选，只是备注，不判断装备使用资格
- 每个指标填写名称、单位、当前完整角色面板和希望的方向
- 先选择目标最低成本或Pareto取舍，不必填权重；只有高级加权模式填写权重，至少一个大于0，分数仅表示个人线性偏好
- 不知道的必要数字留空。它会保存为 `null`，阻止计算，不会悄悄当成 0

### 2. 候选装备

- 普通部位使用中文下拉菜单，内部保留稳定标识，例如武器 `weapon`、鞋子 `shoes`
- 自定义部位使用小写字母开头的标识，只允许小写字母、数字、下划线和连字符；同一部位必须用同一标识
- 填确认报价和额外费用；花费始终是两者相加，不预扣旧装备售价
- 已有物品的报价设为 0，但额外费用仍需填写或确认
- 属性二选一：相对当前同部位的净变化，或仅换该件后、同一测试状态下的完整角色面板
- 装备物品原始属性不能充当完整角色面板；切换录入方式会询问是否清空旧属性，避免混用
- 来源、证据与备注可展开填写。来源文字不会被自动访问；整份比较与入选候选的备注会在结果中保留，并明确标为未参与约束计算

新建候选的报价、费用与全部指标均为未知。兼容旧输入时，省略 `fees` 按契约代表 0；表单明确显示该兼容默认，真实使用仍应确认必要费用。

### 3. 限制与取舍

- 记录当前各部位装备名，或锁定某部位保留当前装备
- 设置最终面板最低值、最高值与最多替换件数
- 按需选择必选、排除与互斥候选
- 门槛留空表示不设置该限制，和必要测量值未知的含义不同
- 配置互相矛盾时显示错误；目标可合法配置但无法达到时，计算返回“没有可行方案”

### 4. 多方案比较

- 最多 8 组预算试算：保持主目标模式与约束不变，只改变预算
- 最多 8 组权重试算：保持主预算与约束不变，只改变权重
- 最多 2 组手动 A/B：勾选装备；不勾选表示零换装
- 手动方案可以超预算或达不到目标，结果会明确标出原因；同一方案选同部位多件、重复或未知 ID 属于错误输入

### 5. 确认与计算

- 核对报价时效、费用、实测状态、使用资格及套装/特技联动
- “已确认”只是用户声明，不是工具独立核实
- 输入检查通过后点击计算，阅读零换装基线、目标最低成本/高级加权模式的首选（Pareto不选唯一首选）、负向取舍、证据与诊断
- 即使基线未达到目标或不在帕累托前沿，也始终展示
- 更多备选和帕累托取舍放在折叠区域，避免只看单个分数

## 草稿、报告与文件安全

- “保存草稿”下载输入 JSON；未填数字可按 `null` 保存和再次打开
- 无效数字文本（如 `12x`）会留在原输入框，修正前不能保存或做结构修改；不会变成 0
- 输入数字经 `MHXYEngine.numeric` 与精确解析/序列化处理，不经过浮点 Number 转换
- 高级 JSON 可选。编辑后必须显式“应用 JSON”，否则计算和保存暂停；表单修改会刷新尚未手工编辑的 JSON 视图
- 打开新草稿或重载演示前，存在未保存修改时会询问
- 文件解析与显示失败不会替换旧草稿/报告；读取期间编辑表单不会被迟到文件覆盖，多次选择时最后选择优先
- 输入文件上限 1,000,000 字节。拒绝重复 JSON 键、超过 32 层嵌套、非法结构与超限数据
- 没有自动保存、浏览器存储、追踪或后台请求。刷新或关闭前请主动下载草稿，并核对浏览器下载目录
- 所有来自文件和表单的动态展示都使用文字节点，不执行文件中的 HTML 或脚本

计算结果支持 JSON、文本、CSV 与 HTML 下载。CSV 的文字单元格由引擎做公式注入防护；HTML 导出为转义后的静态报告，无脚本。JSON 保留全部精确数字字符串与枚举摘要。

### 打开 Python 生成的结果

顶部“已有 Python 计算结果？”区域可以打开本地报告 JSON，输入表单不会被替换。报告上限 16,000,000 字节，指标、选择、备选、帕累托、情景、核对项及文字有额外结构上限。金额、属性、已使用权重与分数必须为精确数字字符串；无权重模式的weights/score为null；JSON 数字仅允许安全范围内的整数计数。

导入报告会显著标出：与当前表单独立、只展示报告声明、没有重新计算或核价。旧报告缺少可行性标记时，不会显示“满足约束”。编辑表单会收起旧结果，重新计算后才能按新输入导出。

## 独立修炼与宝石工具

页面底部提供折叠的独立资源试算，适用范围为梦幻西游电脑版时间服。它们不写入配装输入，不自动改变候选面板。输入与最近有效结果可单独保存为 `mhxy-resource-trials.json`；资源区域的“打开资源草稿”可以重开本版v2、旧v1及无schema导出。导入会丢弃缓存结果，须重新计算；这不是主配装输入文件。另可导出含结果、边界和官方来源的.txt说明。

- 普通帮派修炼：显式填写类型、当前/目标等级、已确认上限和本级经验。计算经验、普通购买次数、游戏币和资材消耗；累计帮贡与入帮天数是严格大于门槛，不是扣除项
- 普通宝石：显式填写当前/目标锻炼等级，逐级输入所需宝石的手工报价，单位为游戏币两的整数。缺任一级报价，总价显示未知，只另列已知小计
- 同时区分全部新增锻炼材料下限、目标等级单颗材料下限和宝石增加的原始装备属性。材料下限不等于预计花费；不含失败损耗、体力、费用或库存抵扣
- 使用资格、部位、宝石种类数、等级上限及例外需人工确认；原始装备属性不是最终角色面板或实战收益
- 每次结果提供固定官方来源链接与核对日期。只有用户主动点击“联网查看”时才会打开官方网页

完整规则和边界见 `../references/resource-calculators.md`。

## 模型边界

工作台不登录游戏、不读取游戏客户端、不买卖或操作账号、不抓取交易平台、不核验市场价格。配装优化假设每个候选相对当前同部位的净变化可相加，不包含未录入的套装联动、阈值、隐藏属性、战斗公式或装备资格限制。线性偏好分不能解释为伤害、治疗、胜率或真实最优配装。

主配装输入上限：12 个指标、12 个候选部位、64 个候选、10,000 个组合；最多 6 位小数，单个输入数值绝对值不超过 10^12。详细约束以 `../references/input-format.md` 与引擎检查为准。

自升／替换页面覆盖upgrade_compare；同类估值样本、宝石溢价、总养成账本、目标差距、收入情景以及其他高级路线仍由Python／聊天助手提供，没有对应的独立网页表单。

## 新增养成计划工作区

同一个草稿保留三套表单，可按首页入口或顶部选项切换。默认空白，合成演示主动载入且编辑后仍标记演示；真实决定请另开空白。各金额保留精确小数，引用来源作为文字处理。

### 完整宝石

填写装备原始等级、部位、实际当前/目标锻数、已有宝石类型与特效；人物等级可选，未填不能称已可穿。逐级清单自动生成，每个新增等级要一颗同级石。先明确库存未知、没有或逐级数量；机会成本不同于历史买入价。可选成品路线独立核对资格、同目标依据、购入费、卖旧状态和时间限制。

### 混合修炼

填写实际修炼种类、当前/目标、进度和上限。启用混合比较时才需要道具每颗XP、确认依据、单价及混用资格；本期最多可用颗数填0可只算普通路线，目标已达到无需采购。猎术可用原普通资源工具，宠修/降修等使用Skill扩展路线。

### 共同预算

从明确目标、当前现金、预留金开始，按需要添加分类预算和共享资源。每个候选的目标、前置、互斥用选择控件关联；效果依据和费用必须明确，未知项目留待核实。明确已完成的项目可满足前置和其目标，不再重复支出或耗库存。余额和库存按本次实际值填写，程序不会把上次建议当成已经执行。

### 更新、保存与导出

- 同一个养成草稿保存全部三套输入、核价口径、完成勾选和备注；未填完也可保存
- 切换任务保留输入；修改、切换或新文件打开后旧结果失效，须重算
- 文件解析、结构或版本错误不替换当前草稿；取消读取、读取期间编辑和后选文件都有保护
- 比较日期与每条报价观察日期分别保存；打开历史草稿提示旧核价日，默认“今天”按浏览器本地日历，原报价不会自动重标
- 切换宝石种类不能沿用原种类报价/库存；修改装备或目标后，成品同目标声明须重新核对
- 共同预算修改已经关联的目标定义后，须确认现状是否已达成及每条原候选是否仍达标；保留实际已完成项目和当前余额，不因改字重复收费
- 可读计划.txt与计算证据.json用于复核；继续编辑须另存计划草稿
- 三套表单没有跨表单自动成本依赖：共同预算的整项目金额需更新。需要一处事实联动多个步骤时由宿主使用单一dossier



## 从问题继续而不重填

首页识别到足够的明示资料时直接按实际字段计算，缺项不设0，冲突不静默选。必要字段和原话短语经你核对后带入目的页，目的页仍需明确应用。养成v1和资源v1可以迁移到v2；问题出处随草稿/报告保留。普通规则修炼无需无关区服。完整协议、历史/复制链接隐私与边界见 `../references/question-intake.md`。
