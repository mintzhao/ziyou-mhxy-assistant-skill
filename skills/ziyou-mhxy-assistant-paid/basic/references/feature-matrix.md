# 哪个入口能做什么（基础版）

用户在支持本地 Skill 的聊天助手中直接提问。宿主整理输入并运行 Python 标准库工具，也可从命令行使用。

| 需求 | 工具入口 | 边界 |
|---|---|---|
| 普通修炼、普通宝石数量与费用 | resources.py | 已有经验和上限按实际输入；未知不填0 |
| 自升与成品比较、可比报价、目标差距、分币种总账 | decisions.py | 保留现金、机会成本、条件卖旧和报价来源 |
| 完整普通宝石自升与成品对照 | plans.py --kind gem_upgrade | 核装备资格、各级报价、库存、费用及预算 |
| 普通点修与经验道具混用 | plans.py --kind training_mix | 核道具经验、资格、完整报价与上限 |
| 多目标共同预算 | portfolio.py | 前置、互斥、共享库存、预留和已完成项目；不自动推断实战收益 |
| 装备取舍 | calculate.py | 最低成本达标、Pareto、可选加权；不证明实战提升 |
| 保存、更新事实与关联重算 | dossier.py | 源档案重新编译，缓存不作当前事实 |
| 经验道具、宠修果、降修提上限、宝石资格、星辉石 | routes.py | 仅明示规则，未知资格须确认 |
| 专注、帮派技能、灵性、珍珠、炼兽笼、分方法修理、练宠场景 | mechanics.py | 保留证据日期；不补造当前菜单、速度或总收益 |
| 玄灵珠条件材料与占格清单 | crafting.py | 失败或未知结果停段；不保证采购数或成功 |
| 公开规则、报价补查 | public_research.py 与宿主只读搜索 | 来源结构检查不替代语义复核 |
| 原文与计算事实绑定 | evidence.py | 不验证归属或事实真伪 |

规则说明见 GUIDE.md 对应 references，保留适用服制和来源核对日。

## 保存与继续

保存 dossier 源档案或编译 bundle。更新报价、库存、当前现金或已完成项目时，保留旧文件，创建新 revision 并重算。旧物未出售到账不作当前现金，预计剩余不作实有库存。JSON、TXT、CSV 或 HTML 结果用于阅读和复核；结果报告不代替可继续更新的源档案。

使用需要宿主读取完整技能包并执行已有 Python。具体输入与来源处理见 question-intake.md，共同计划见 whole-plan-workflow.md。
