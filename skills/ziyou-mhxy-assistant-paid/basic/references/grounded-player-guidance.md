# 真实玩家常见问题：先给可用办法，再保留精确边界

版本：1.0.0（补充普通修理手动步骤与练宠场景区间）。规则引用核验日：2026-10-07 UTC。适用大陆《梦幻西游》电脑版时间服。以下是原创规则归纳与手动决策办法，不是实时游戏状态、完整补丁核验或游戏内实测。历史页面日期、测试/全服日期与核验日分别记录；运行时不联网。

这份指引用于避免“只说缺信息，却不回答已知部分”。首轮先给相关规则或可执行的核对步骤，最多问两个真正影响下一步的问题。已有输入保留原始来源；目标等级、当前等级、社区举例和实际库存不能互换。不靠消耗物品验证未知机制。

宿主根据问题提供说明与引用，不自动推断玩家资格。结构化接口见 [grounded-mechanics.md](grounded-mechanics.md)；原有资源/资格计算见 [verified-routes.md](verified-routes.md)。

## repair

### 80级武器0耐久，不能用帮派，本人打造不足40，怎么办？

**不用先练自己的打造，也有非帮派路线。**先保留玩家是否接受仙玉成本的选择：

1. **愿意用仙玉、想省去找摊位：**打开武器所在物品／装备栏，点武器图标右下角“修理”进入快捷修理。0耐久符合≤10的入口条件；按当前显示费用和提示决定是否继续。官方2015表为≤80级每次10仙玉、补100耐久，但这是历史列价，不是已确认的2026现价。免费仙玉不能用于快捷修理
2. **已有适用且已激活的乾坤石：**右键乾坤石，选择这把武器补耐久。旧官方表的破损乾坤石适用于0–80级人物装备，三失败人物装备也可用。未激活的石头需要仙玉激活，不能把“已有”直接说成免费；石种适用性和激活状态按实物核对
3. **只想用游戏币找玩家修理：**这把武器累计失败须少于3次。右键玩家摊位招牌，查看制造类／打造类修理服务；使用摊主修理能力，本人无需先到40。修理仍可能失败。制造者体力不足会使相应选项置灰，可换可用摊位；当前摊位供应、80档选法和最后买方按钮未完整核验，不编写逐键保证

快捷修理是独立入口，依据其规则可作为不依赖帮派和本人打造的替代；原公告未逐字写“无技能要求”，不把范围推断伪装成原句。2015-07-17发布、07-21测试、07-28全服；2024-05-20发布的免费仙玉限制于05-21全服，亦排除用免费仙玉购买乾坤石。具体来源、各公告发布日期与生效日见[修理路线证据](repair-route-evidence.md)。

如果玩家本来就想自行普通修理，再给**铁匠铺**及条件：80级武器要求打造技巧至少40，累计失败少于3次，每次耗体力且可能失败。本包没有核实当前自修NPC、坐标或完整菜单，不把打造书铁界面当作修理操作证据，也不把学徒小麦当80级修理NPC。操作后按真实耐久和失败次数重新判断，不连续盲修。

首轮已能给路线，不等填完资料才回答。最多只补两个真正影响选择的信息槽，例如“是否只接受游戏币？”以及选择普通修理时缺失的“累计失败几次？”；本人打造已知不足40时不重问，不要求先练技能。已明确不能用帮派就不再推帮派。只作手动指引，不购买、激活或替玩家修理。

### 三次失败的召唤兽装备，用珍珠怎么修？

**可以用珍珠。**2013-03-11发布的测试公告明文允许失败三次宠装使用珍珠，03-12测试，03-18发布的后续公告确认03-19全服；不是从天眼珠与珍珠分段描述推出来的资格。

时间服按以下官方文档级路线操作：

1. 选择满足“珍珠等级+5≥宠装等级”的珍珠。例如105宠装可用100级珍珠，115宠装可用110级珍珠；这不代表本服市场一定有货
2. 右键珍珠打开“使用珍珠”界面。宠装还穿着时切到“召唤兽装备栏”；已在背包时切到它所在的“道具”或“行囊”栏
3. 选择需要补耐久的那件宠装，按游戏当前提示完成。名义补200耐久，受装备耐久上限限制；不是补200点耐久上限，也不据此声称清除失败次数

不必先去铁匠铺或NPC，不必为了证明三失败资格寻找未证实的预览。右键珍珠入口2015-06-09测试、06-16全服；珍珠／乾坤石四类栏位切换2026-03-31测试、04-07全服。最后消费按钮的准确文字、位置和是否一定显示数值预览未实测，不写死“点修复／确定”。

天眼珠仍有等级≥宠装等级、类型影响成功率、灵气影响恢复量及三次失败禁用的独立限制。时间服乾坤石给宠装补200耐久于2026-04-07全服，限已激活且石种适用；三失败宠装乾坤石资格仍未直接证实，所以这一特殊状态给已核的珍珠路线，不把乾坤石当确定保底。

畅玩服另于2026-07-28全服支持“道具行囊→召唤兽页签→先选召唤兽→右键珍珠／乾坤石”直接定位该宠装备且不用卸装。这个选宠物自动定位细节只作畅玩服说明，不移植到时间服，也不把pc_time接口改写成跨服制支持。

### 人物珍珠与恢复量的剩余边界

人物珍珠完整公式、等级／耐久门槛和三失败资格仍未完整核验，不套用宠装200、固定100或社区20%公式。人物乾坤石旧说明明确名义补100且受上限限制、三失败可用，石种和等级范围另核；2026宠装补丁不能变成人物统一价格。

若当前客户端实际有扣除前数值预览，可记录本次物品、材料、状态、观察日和报价作条件比较；没有预览就保留精确恢复量未知，不要求花一颗试效果。对已核宠装珍珠三失败资格不再额外要求预览才能答“可用”。类别不明时先问人物还是召唤兽装备；方法不明时再问拟用哪种方法，最多两个必要问题，已给资料不重问。

完整[修理证据与日期](repair-route-evidence.md)列出普通修理、快捷修理、免费仙玉、玩家摊、三失败宠装珍珠、右键入口、时间服切栏及畅玩服入口的第一方原文。引用核验至2026-10-07，不代表覆盖之后全部改动或已经实机执行。

## scene-leveling

### 35级宝宝有大龙带，不吃月华露，去蓬莱练到150？

先回答当前地点是否适合：官方表列蓬莱仙岛的宝宝获经验区间109–159、满经验区间129–139，35级不在获经验区间内，不能把蓬莱当作35级起步方案。当前可用来核对的满经验参考包括大雁塔六层28–38、海底迷宫二层35–45；目标末段可参考墨家禁地140–150。满经验区间不等于每场经验数、速度或省钱保证。

宿主调用 `mechanics.scene_leveling`，保留current_pet_level=35、target_pet_level=150及exclude_yuehua=true；可用scene=蓬莱仙岛供核对。结果列所问场景检查、当前满经验选项、仍有玩家等级/组队条件的选项，以及从固定玩家0–175行取出的区间覆盖示例。不能把示例叫最优路线、把覆盖到150叫账号已能练到150，或把未覆盖段叫所有方法都无解。

人物等级是官方表的另一个选行条件，不是宝宝等级。月宫、青丘、鬼市、芙蓉园等按玩家等级分行；人物等级未知时保留条件行，即使已知也只说明匹配表内档位。原表未解释混级队伍如何选档，不能自行规定用大龙等级、队长等级或队伍最高等级。场景可进入、人物携带上限、队伍安全和前置另核。

首轮最多补两个真正影响选择的问题：“你的人物多少级？”“现有大龙是免费带，还是收费带？”已知则不重问。免费带只意味着这笔带练费为0，仍不能推导全程现金为0；收费且无报价时不编价格。人物低于目标也不能仅凭这张表判断目标必达。保留不要月华露的限制，不反过来把月华露列成主推荐。

炼兽笼、修业点可作为另核资格的备选，不用假设人物140/已有笼子的例子替代现有带练方案。到150的笼子人物等级条件可以核对，但不要为这个目标索取不改变该项阶段上限判断的飞升/渡劫资料后才回答场景。没有同条件实际经验速度、总经验及费用记录时，最优路线、总小时、总现金均保持未知。

## xiuyedian

### 宝宝目标139，什么时候吃修业点最划算？

修业点增加召唤兽等级经验，不能套召唤兽修炼、修炼果或人物点修公式。目标139不代表当前139，也不能仅凭目标倒推出人物等级、剩余经验或购买点数。

**先给已知资格**：通过交易、给予或摆摊购买取得不足24小时的召唤兽，不能立即用修业点加经验。游戏内NPC会提示最早允许兑换的时间；该提示2026-06-02在部分服测试、2026-06-09全服放出（该公告页面发布日期同为2026-06-09）。这不是确认24小时限制最初在当天新增。没有取得方式/时间时资格为未知，不能自动当作已满24小时。这是2026规则边界，不能倒灌成2019历史帖子当时的规则。

**在界面确有无消耗预览的条件下，可以做的手动方法**：

1. 记录宝宝当前等级、本级经验、目标，以及剩余自有点数；先看是否允许现在兑换
2. 在确认扣点前预览一个小批量，记录点数和预览经验。此时仅比较实际显示的结果，不假定每点经验公式或200点必定最佳
3. 接近目标时缩小批量；只有当前界面/已核目标经验足以判断不会超出目标时才确认。看不清跨级结果就暂不确认，不把“不超139”写成保证
4. 每次实际兑换后重新记录等级与经验，再安排下一批。跨级后重新预览，不沿用上一批的每点兑换率；剩余点数以实际扣除为准

没有不消耗点数的预览时不要求试兑。缺当前经验/目标经验表或跨级语义时，不输出精确最优点数、确切费用或必达时间。暂未核实基础兑换公式、取整与跨级批次更新，不上线社区公式拼成的“最省钱计算器”。

**决定“最划算”之前区分目标**：最少点数、最少新增现金和最快到目标可能不同。自有点不代表零机会成本，买点须有同服、日期、币种和取得方式；24小时限制可能改变时间路线。首轮优先问当前等级/本级经验及游戏内可兑换时间，下一轮再问玩家更在意省点、省钱还是省时间，不重复已有资料。

## gem-operations

### 买好9/10级宝石后怎么打，会失败吗，要技能吗？

**先分操作**：已有9/10级石并直接镶嵌，不需要为了镶嵌再合成一次。旧官方宝石页说明在铁匠铺按打造式操作放入装备和宝石；这不是证明装备打造的技能门槛也适用于宝石镶嵌。

- 镶嵌前先核部位、原装备等级、当前锻数、已有宝石种类和精致/无级别特效。普通宝石逐级追加，每个新增等级各需一颗相应等级石；不能跳级，每件最多两种类型
- 普通80级腰带一般到8锻；精致上限多1，仍不能直接当10锻路线；无级别另核。普通100级鞋由8到10须9级、10级黑宝石各1颗，且部位/种类/特效等其余条件也须通过。材料算术不能代替资格检查
- **直接镶嵌会不会失败、需不需要生活技能**：已读官方页没有明确写这两项。本包保留未核实，不答“肯定不失败/无需技能”，也不反过来声称必须学合成技能。可让玩家提供当前操作提示，不能要求试消耗
- **自行合成先看目标等级**：2024-05-21全服调整后，目标12–20级在两个前一级同类主料外还要交指定低阶同类石，该次高阶合成必成。12级例：11级两颗，加3、5、6级各一颗；20级例：19级两颗，加17级一颗、18级两颗。完整附加表与既有资源计算器一致，见resource-calculators.md
- **宝石工艺是资格门槛**：目标2–3/4–5/6–7/8–9/10–20级，最低技能为3/4/5/6/7级。在打铁炉/缝纫台操作；不是仅可选的成功率提升
- 目标2–11级不能从上述公告推出必成；旧页有失败损失一颗的描述，当前精确概率未核。高阶必成不保证从一级合成的全路径材料数，不加入编造的概率、体力、手续费或现金
- 先区分产物目标与现有材料：“我有两颗11级”只说明原料，不当目标11；“11级合到12级”明确产物12。宝石工艺目标7级属于技能，不当产物。和/或/、及跨分句延续的清单沿用库存/原料/产物角色；明确目标12与原料3/5/6不冲突，明确目标12或13则需澄清。只作有界规则指导，不自动登记库存或消费
- 缺目标等级先说明低/高档边界，再问“要合出几级普通宝石”；不要问装备等级/特效来阻塞纯合成问题。指定历史日期先按当时发布范围核对，不把2024全服规则倒灌过去。普通石不套星辉石/玄灵珠/精魄灵石；合成的必成和技能门槛也不能移植成镶嵌保证

例题“80腰带和100鞋均8锻，买9/10直接打”：先回答两件上限不同，再给逐级材料、地点，并分别说明失败/技能未知。只需先问腰带特效，不重问已给的两件等级或锻数。不给80腰带套100鞋结论。

有报价后，自升新增现金=实际缺少的9/10级石报价+实际费用；与同目标成品总价−旧装条件净回收比较，并单列属性差、交易费、先买后卖的现金需求。没有报价就给条件式，不断言成品总是便宜。库存机会成本与现付现金分账。

### 20个空位买一级玄灵珠太累，怎么分批合到6级？

2. 从实际可用库存列出各级、类型、转移锁；提前标记不能拿去别处消耗的高阶附加材料。合6级最后一步所需的额外3级珠必须保留
3. 在空位和当前合成材料已确认后，每批只补下一次确定合成缺的材料；手动合成一次，记录实际消耗、产物和剩余空位，再补下一批。仓库/行囊是否可直接读取按真实界面确认，不凭名称假定
4. 若从已有/已购中间珠开始，可先核算4–8级的确定性部分。缺的2/3级材料列为“取得需求”，不能默认为从一级无损合成
5. 低阶合成发生未知/失败结果时停下，记录剩余库存重算，不能沿着原成功假设继续扣料

**只有满足条件才能称容量可行**：每一步同时保留所有中间产物与附加料，核对叠放、实际可用格、输出是否需先空一格、资金和体力；展示前后库存与费用。保守“一物一格、另留输出格”可作为显式场景假设，不是官方占格事实，更不证明真实最少往返。没有同条件的可行旧方案和新方案对比，不宣称节省多少点击或搬运。

目前仍未知：2/3级当前必成性与失败概率/后果细节、当前堆叠上限、袋/仓库可达性、选中材料是否继续占格、输出格检查时序、全等级合成费/体力、商店实时价/库存、批量按钮。早期图片20体力/10000两仅为旧界面单例，移除珠子的费用表也不是合成费表。不能因此报从一级到6级的确定购买总数、有限最坏重试数或20格最短路线。

## market-evidence

### 天地改装、善恶宠装估价与三速度涨价：怎样继续到可作决定？

**改装顺序**：先固定玩家最新目标和同状态面板，定位实际失败场景（例如哪档天地、队伍配置、先倒地还是伤害不足）。预算只采用用户明确金额，不把答主随口的5000或市场观察价当用户预算。候选先记录可核的净面板变化、现金、耐久/维修负担、套装与前置；实战收益未知就单列，不编物爆收益或2200一刀切合格线。得到可比候选后才按真实目标排最低成本或Pareto取舍。

**三图宠装估价**：先读取图片或接收完整属性文字、确认是买还是卖及要价、区服/日期/币种。未见图片不能将回帖描述当玩家装备属性。把底子、灵石、点化、失败/耐久分账，但造价不是成交价；同条件挂牌与已成交分别展示。诸如“3000:198”“点化450”没有单位时不自动换成人民币。

**涨价原因**：先检查比较对象是否同部位、主属性、条目/数值、锻数、区服及时间。双速一封印、三速主伤、三速主防不是同一商品序列，2025单次挂牌也不是2026现价或成交价。取得相近条件的跨期挂牌与成交、供应数量和需求变化证据后，才报告涨幅；竞速、PK、门派热度、控价只能列为待验证假说，不能用社区共识证明因果。

**最小证据卡**：物品完整属性与状态、区服、观察日期、币种/单位、卖方要价或真实成交、来源、费用、与玩家目标是否一致。用户已给的内容不重问；只补影响眼前决定的1–2项。报价筛选与账本工具见 [decision-calculators.md](decision-calculators.md)，不自动爬价、不承诺保值或投资收益。
