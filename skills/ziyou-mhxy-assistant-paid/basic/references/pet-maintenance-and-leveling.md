# 召唤兽装备修复与练级：可纳入规则

核验日期：修复分项、练级地点与炼兽笼均于2026-10-07（UTC）复核。适用范围：《梦幻西游》电脑版时间服官方公开资料；不套用手游或赛季服；畅玩服仅在明确标注的小节独立说明。以下文字为本次独立归纳，不复制官方实现。

## 召唤兽装备修复

三次修理失败的召唤兽装备仍可用珍珠，这是2013-03-11发布的官方公告明文规则，2013-03-12测试、2013-03-19全服。珍珠等级+5≥宠装等级；名义补200耐久，受装备耐久上限限制。例如115级宠装可用110级珍珠，不必为了等级门槛买120级；不保证市场供货，也不宣称增加耐久上限或清除失败次数。

时间服手动路线：右键珍珠打开“使用珍珠”界面→宠装穿着时切“召唤兽装备栏”，已卸下则切所在“道具／行囊”栏→选目标宠装，按当前提示完成。右键入口2015-06-16全服；四类栏位切换2026-04-07全服。无须先跑NPC、铁匠铺或寻找未证实的资格预览；最终消费按钮文字／位置及一定存在数值预览未实测，不写死。

天眼珠的三失败禁用规则不扩大到珍珠。已激活乾坤石给宠装补200耐久于2026-04-07在时间服全服放出，支持石种与宠装等级上限见2026-03-31官方表，不照搬人物石头范围。三失败宠装的乾坤石资格仍未直接证实；三失败问题采用已核的珍珠路线。旧乾坤石页“只允许人物装备”已被这次新增规则覆盖。

畅玩服单列：2026-07-20发布、07-21测试、07-27发布后续公告并于07-28全服的入口是“道具行囊→召唤兽页签→选召唤兽→右键珍珠／乾坤石”，直接打开该宠装备界面，无须卸装。此处仅说明版本差异，不把该自动定位细节移植到时间服，不扩充pc_time工具支持范围。

## 场景练宠：先核当前等级，再给有条件的覆盖示例

`references/pet-scene-ranges.json`保留官方《宝宝练级地点》的79条数字记录。页面日期2023-03-06，引用核验2026-10-07；只分发原创结构化事实和来源链接，不分发原始官网页面。宿主通过 `python -X utf8 scripts/mechanics.py input.json --kind scene_leveling` 查询，接口详见grounded-mechanics.md。

### 三列必须分开

- 玩家等级（player_level_range）：这一行的选用条件。它既不是宝宝等级，也不是已经确认的场景进入条件
- 满经验等级（full_xp_pet_level_range）：宝宝满经验等级的闭区间
- 获得经验等级（xp_pet_level_range）：宝宝可获经验等级的闭区间；在此区间内不等于满经验

多数行的玩家等级范围为0–175。月宫、青丘、鬼市、芙蓉园按不同玩家等级分行；即使提供人物等级，也只确认与表内哪个档位匹配。原表未说明混级队伍如何选档，不能默认为按队长、大龙或最高等级成员决定。条件行在 `conditional_full_xp_options` 保留条件，固定行的当前满经验候选在 `current_full_xp_options`；两者都不自动证明场景进入、人物携带上限、队伍安全或前置已满足。

### 35级宝宝到150：眼前能直接回答什么

蓬莱仙岛列出的宝宝获经验区间是109–159，满经验区间129–139。35级不在其获经验范围内，不能把“去蓬莱”作为35级的起步结论。大雁塔六层满经验28–38、海底迷宫二层35–45，包含当前35级；墨家禁地满经验140–150，包含目标末段。

可以据表给一条整数等级无空档的覆盖例子，例如：海底迷宫二层35–45 → 地狱迷宫一层40–50 → 地狱迷宫三层46–56 → 北俱芦洲54–64 → 龙窟二层62–72 → 龙窟三层68–78 → 龙窟五层76–86 → 龙窟七层84–94 → 麒麟山93–103 → 女娲神迹104–114 → 小西天112–122 → 小雷音寺121–131 → 蓬莱仙岛129–139 → 墨家禁地140–150。各数字是场景的完整满经验区间，重叠处不是规定必须何时换图；也可以先用塔六28–38再接海底二。它只是表内覆盖参考，不是工具固定唯一结果或经过速度/路程优化的路线。

`level_coverage_example`仅采用玩家等级固定0–175行，不能用未确认的变动玩家档位补全确定路线。`uncovered_pet_level_ranges`报告当前到目标区间中未被这些固定行满经验范围覆盖的等级段；这不等于全部场景无经验，也不等于所有其他练法无解。`target_level_reachable`、`optimal_route`、`total_time_hours`、`total_cash`在本接口中固定为null；需要另外受支持的资格、速度和费用证据才能作进一步判断，不能从覆盖图直接填出数值或true。

有现成大龙且在意省钱时，最多先问人物等级和带练是否收费；已明确就不重复问。免费带只免去该项带练费，不能直接把点卡、补给等整条路线费用置0。`exclude_yuehua=true`保留不要月华露的限制；未排除也不代表工具已经比较过月华露。炼兽笼或修业点只能列为分开检查前置的备选，不冒称最便宜、最快或必可用。

来源：[官方宝宝练级地点](https://xyq.163.com/introduce/cy008.html)，页面日期2023-03-06，引用核验2026-10-07。当前客户端具体经验、组队解释、速度与收费未实测。

## 从0级练到119级：先验门槛与可执行路线

0级宠不能直接放炼兽笼。先通过适合等级的场景战斗练到至少30级，再考虑炼兽笼路线。官方练级地点表列出0—9级宝宝可在东海湾获得满经验；后续应依据宝宝等级选择表中的满经验区间，不应把一处场景保证为0到119全程最优。

炼兽笼需放在庭院，一个庭院最多2个，但每次只训练一只宠；使用时角色不能移动。召唤兽至少30级才能使用；笼子上限是人物等级+10，同时受角色阶段上限约束：未飞升150、未渡劫160、已渡劫180。若计划靠笼子达到119级，人物至少109级是必要条件。

只有用户选择进一步比较笼子时，才分轮补齐影响该方案的资料：人物等级、是否已有庭院和笼子、当前宝宝等级与已存经验、在线时间及精修时间的生效状态；不再把双倍时间作为笼子效率的必要追问。完整cage_eligibility接口还需角色阶段；先回答到119/150的已知人物等级必要条件，不为不改变该阶段上限判断的资料阻塞场景建议。官方页面列NPC出售笼子为200万梦幻币；已有笼子不能重复算这项购置成本。页面未给0→119经验总量、每小时经验、具体点卡价格或总训练时长，因此不能仅用这页报“总价/几小时包到119”。

时间及资源约束：每次获得经验原本扣2点体力，体力不足时经验减半；使用2小时后不再扣体力；每天最多4小时。注意“体力不足经验减半”和“2小时后免体力”是两条不同规则，不能推导全天固定每次扣体力。

现行加成规则：炼兽笼经验不受双倍时间影响，仍受精修时间影响。2015-06-09维护公告第8项在部分服务器测试，2015-06-16全服放出，覆盖2012介绍页仍保留的旧加成说法。2015公告所说基础经验变为2倍、领取精修后为3.2倍，都是与调整前同一基础经验相比；3.2不是当前基础上的倍率，不能据此填每次经验、每小时速度或0→119总经验。2026-01-27测试、2026-02-03全服的炼兽笼界面优化可显示精修时间是否生效，只是现行加成的旁证，没有恢复双倍影响；本工具不读取玩家实际生效状态，也未做游戏内实测。

日期接口：cage_eligibility新增可选as_of（YYYY-MM-DD），省略时固定用本包核验日2026-10-07，不取运行电脑的今天。knowledge_checked_date与rule_snapshot_date分别记录核验日与适用快照；as_of不是重新核验。experience_time_rule把2015-06-09测试与2015-06-16全服分开，早于全服日时double_time_effective与jingxiu_time_effective均为null，不追溯套用后来全服规则；这也不自动证明测试期间某个具体服务器已采用该规则。jingxiu_status_display另按2026-01-27测试／2026-02-03全服分界，早于全服日不保证已有状态显示。原等级门槛与购笼资格计算保持不变，仍不提供完整练级现金、时长或XP计算。
