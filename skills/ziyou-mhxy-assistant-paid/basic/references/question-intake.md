# 从用户问题准备计算输入

由宿主理解自然语言，整理本地 Python 工具需要的字段；用户无需编写 JSON。

- 复用明确给出的对象、当前/目标等级、已有经验、上限、预算、报价和库存，不重复询问。
- 区分实际事实、假设、举例、否定和引用；冲突或未知值保留待确认，不填0。
- 金额保留币种、区服、观察日期与来源短语；旧报价不因为重新计算变成新报价。
- 多对象或多组数字有歧义时只询问当前计算必需的信息。
- 只把必要事实写入输入或 dossier，不保存无关身份信息。

例如防御修炼2→4、本级已有123经验、上限4，应按这些条件计算，不改成0经验。角色等级、帮派开放和实际资格另按对应规则核对。

重新使用已有档案时，保留原文件，用新版本记录更新的事实和来源，再重新计算；缓存结果不能代替当前余额、剩余库存或已执行项目。
