# 命魂之玉与玉魄赠送灵尘：证据边界

核验日期：2026-10-06（UTC）。来源为《梦幻西游》电脑版官网2025-04-16发布的“命魂之玉”，直接读取HTTP 200：

## 官方明确写出的两项规则

定位“上古玉魄”第4项：
- 第（1）项将每条与基础属性相同的附加属性，定义为自动获得1级灵尘等级
- 第（3）项规定，超过人物等级/10的灵尘等级所增加的附加属性，装备后按50%生效

## 可回答什么

赠送的+1/+2在该页的定义中属于“灵尘等级”。把上述两项合起来理解，衰减风险应连同赠送等级一并判断，不能假设赠送等级天然豁免。注意：这是依据官方两项规则作的组合推论；页面没有单独用问答形式明确回答“赠送等级是否参与衰减”。

69级的6+1、6+2分别对应总灵尘等级7、8，均跨过69/10=6.9这个界限，因此不能按全额获得所有额外灵尘收益来购买。该页没有交代临界小数如何处理、是否按整级档位或属性值取整；不输出6.5、7、6.95等精确“等效段数”，也不把整件玉魄全部属性说成减半。

175级的15+2总等级为17，不超过175/10=17.5；按该页规则定义，这个例子不会仅因灵尘等级超限触发50%衰减。这同样是算术推导，不是游戏内实测。

衰减条款限定的是超限灵尘带来的“附加属性”。不能据此断言基础属性、奇袭概率、开光孔等一并减半，也不能反过来推定赠送等级会解锁所有按“镶嵌特定等级”触发的奖励。
