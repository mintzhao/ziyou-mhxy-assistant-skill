# 自游·梦幻助手（基础版）

版本：1.1.5 · 作者：自游

基础版免费使用，无需购买、激活码或单独注册。已包含本包全部现有功能。你使用的聊天助手可能单独收取模型或服务费用，具体以该助手为准。

修炼要花多少钱？装备自己做还是买现成的？预算有限先提升什么？告诉我你的问题，有装备截图或报价也可以一起发来。自游·梦幻助手帮你算清花费、比较选择。

不只是做养成计划：可以问已覆盖的玩法规则、算材料和费用、比较装备或养成路线，也可以保存方案以后继续更新。规则问答只回答有可靠依据的部分，不是覆盖全游戏的百科。

## 怎么开始

1. 下载完整的基础版安装包 ziyou-mhxy-assistant-1.1.5-basic.zip，不要只下载说明文件
2. 按 支持 Skill 的聊天助手提供的技能导入方式导入完整压缩包或解压后的完整文件夹
3. 确认技能名称“自游·梦幻助手（基础版）”，然后像平常聊天一样说出问题

聊天助手需要支持读取本地技能；使用计算功能还需要能运行已有的 Python。核心程序只用Python自带标准库，不需要另装第三方库。普通玩家不用写代码、不用填数据文件，也不用先填一大张表。宿主不支持脚本运行时，计算功能需要可执行 Python 的环境。

第一次不知道问什么，可以直接发：

> 这个技能怎么用？我应该先告诉你什么？

也可以从自己的问题开始：

- “炼兽笼受双倍时间影响吗？”
- “我想把攻击修炼从10点到15，要多少游戏币？”
- “这件装备自己打宝石，还是卖掉换成品更划算？”
- “我有1000万两，想先补修炼和宝石，帮我排一下先后。”
- “这是我的装备截图和卖家的报价，帮我看看还缺什么信息才能比较。”
- “这个新玩法你这里没写，能帮我查一下官方规则吗？”
- “这几条公开报价能读到吗？帮我分清挂牌和成交，再比较。”

上面的等级、段数和金额都是虚构的提问示例，不是你的角色资料或区内行情。

## 我需要告诉你什么

先说一件事：你现在想解决什么问题。已经知道的条件顺手说就行，例如现在的等级或进度、目标、可花预算；不知道的可以直接说“不知道”，不必为了开始先查齐。

涉及买卖或费用时，有报价就一起发，尽量说清价格单位、区服、什么时候看到的，以及是卖家报价还是实际成交。没有报价也能先算需要多少材料，或比较到什么价格值得换。

例如可以直接说：

> 我现在8段，想上10段。帮我比较自己打和换成品。报价还没问，你先告诉我需要查哪些价格。

助手会先用你已经给的信息，只补问这一步真正需要的少量问题。不会让你填写整套资料，也不会把不知道的价格算成零。

## 可以发截图吗

可以。如果你使用的聊天助手支持看图，直接附装备、属性、库存或报价截图即可；清楚可见的信息不用再抄一遍。图片看不清或助手不支持看图时，只需补上影响这次判断的文字。

看图由聊天助手完成，这个技能本身不读取游戏客户端，也不自带独立图片识别功能。截图里的账号、聊天对象等无关私人信息可以先遮住。

## 我会得到什么

- 先给当前能确定的结论和下一步
- 要花多少、需要哪些材料、还有哪些条件没确认
- 比较方案时，分清眼下要准备的钱和卖旧后的条件成本
- 哪个价格或条件变化会让选择不同

普通小问题直接答，不强制生成长报告。涉及几个连续目标时，可以说“帮我保存这份方案，后面继续改”；是否能保存和下载文件取决于聊天助手的能力。下次聊天可以附上保存的方案文件，说“接着这个方案帮我算”。之后直接说“预算改成1500万”“这件已经买了”或“报价降了”，助手会根据新事实更新。不要把计划当成已经执行。

## 需要填写什么特殊格式吗

不需要。正常说话、发已有文字和截图就行。计算需要的内部数据由助手整理、检查和运行，你不用接触代码或命令。

只有你主动想批量导入或自己编辑文件时，才需要技术模板。包里的示例数据不是必填表，也不是推荐购买清单。

## 适用范围与限制

平时直接说“梦幻西游”即可。当前计算和资料按已核验的电脑版常规服（时间服）规则整理。另有畅玩服，以及独立的手游，不能默认规则都相同。你明确说过的版本会沿用；只有版本差异影响这次答案、又无法从上下文判断时，助手才会追问。

如果聊天助手具备获授权的联网工具，可以补查公开官方资料、读取能正常访问的公开报价，再按来源、日期、区服和单位比较。网站打不开时可用你已有的文字或截图继续；没有证据的部分会保留未知。技能本身不带联网爬虫。

它不会自动获取实时区价，不保证收益、保值或实战伤害，也不会登录账号、操作游戏或替你买卖。缺少可靠规则或报价时，会把不知道的部分说清楚。不要提供密码或验证码。

技能计算本身使用本地程序；聊天内容的处理方式、联网和看图能力、文件保存方式及模型服务费用取决于你使用的聊天助手。联网补查是可选能力，未联网也可用包内已核资料和本地计算。

## 运行环境

聊天助手需要能读取完整技能包；要运行计算，还需要能执行已有的 Python。遇到打不开文件或不能运行计算时，先看SUPPORT.md中的对应处理方法。
