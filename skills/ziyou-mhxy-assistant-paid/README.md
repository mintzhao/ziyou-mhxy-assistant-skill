# 自游·梦幻助手

直接告诉助手你想解决的问题，有已有报价或截图可以一起发。可以算修炼和宝石花费、比较装备与养成路线、安排预算，保存方案后继续调整。基础功能免费，无需注册或激活；聊天助手的模型和服务可能另收费。

例如：“攻击修炼从 10 到 15 要准备多少材料？”“这两件装备按 800 万和 1000 万两个预算分别比较。”“打开保存的方案，只把预算改成 800 万两。”

新增跨情景共同方案、已有资产自动分配、角色套装/特技标记组合分析按次收费，当前每次 1 元。先免费核对资料，展示完整摘要和费用，你明确确认后生成账单，再由独立的支付宝官方支付工具付款。保存、补充、修改资料和原有多预算/手动比较仍免费。组合分析包含分配参考和连带影响，不拆单收费。

## 安装与运行

将完整 ziyou-mhxy-assistant-paid 文件夹安装到当前宿主的 Skill 目录或通过其导入功能加载；不要只复制 SKILL.md。basic 子目录是内嵌免费工具，不需要单独注册。主入口符合 Agent Skills 标准，可由支持该标准的宿主读取。

运行计算需要 Python 3.10+，只依赖标准库。远程分析需要可信 HTTPS 访问；截图读取和文件保存取决于宿主。不能运行脚本的纯聊天环境不能假称已计算。各宿主具体路径和验证边界见完整源码目录的 docs/COMPATIBILITY.md；如果只安装本 Skill，按当前宿主的官方安装说明操作。

## 首次付款缺少支付工具

助手会保留你提供的资料。你可以说“请帮我安装并启用支付宝官方 alipay-payment-skill 和 alipay-authenticate-wallet 到当前助手，装好后继续刚才的分析”。

[支付宝官方来源](https://github.com/alipay/payment-skills)当前提供安装命令 npx -y @alipay/agent-payment@latest install，需要 Node.js/npm。安装后核对当前助手实际能调用工具；安装器没有覆盖当前宿主时按其导入方式加载官方完整目录。本客户端不内置或复制支付工具。

安装不会付款，也不等于钱包授权。实际操作按官方入口及你的本次授权执行。已有账单则先恢复原单，不能因安装或换助手重复购买。摘要过期时免费重新准备并展示当前费用。免费功能照常使用。

## 保存、隐私和许可

保存方案后保留文件，下次附上它并说明变化。助手沿用事实与来源日期，不把计划当成已经执行；不自动找资料或云同步。远程准备会向配置服务发送必要的分析资料，不要提供游戏密码、验证码或无关个人信息。
