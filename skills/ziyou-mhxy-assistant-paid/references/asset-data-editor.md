# 公开客户端的免费资产资料编辑器

`../scripts/asset_draft.py` 是中性资料的本地纯数据层，随付费客户端提供。它能从空资料开始创建、检查、按稳定编号补答和保留来源历史；无需安装私有应用或先获得私有应用生成的文件。玩家说中文、补数字或提供图片，由宿主提取并明确确认事实，不要求玩家手写 JSON。

此文件只依赖 Python 标准库（copy、dataclasses、datetime、decimal、hashlib、json、re）。没有私有运行时导入、免费基础版运行时导入、分配/组合求解器、网络、文件操作、报价下单、支付凭据或结果缓存。基础版原文件没有改动。

## 调用契约

宿主通过相邻的 `remote_client.py` 的 `asset-create`、`asset-load`、`asset-save`、`asset-edit`、`asset-inspect` 入口使用它。文件路径由调用者明确选择；不设置默认资料目录，不自动寻找历史资料，不云同步。读取、重复键检测、文件大小和普通文件/新文件检查由客户端 I/O 层负责。纯模块不会读写文件。

直接集成时提供以下接口：

- `create(request, source, ambiguities=None, combination=未提供)`：返回完整新 v2 资料。省略组合字段、显式 null、空对象不同，不自动补事实。
- `checked(data)`：校验整个中性文档并返回深复制。接受 v1/v2，读取 v1 不迁移、不重写。
- `content(data)`：选择参与内容哈希的 request、ambiguities 和存在时的 combination。此函数是内容视图，不承担校验或深复制；调用者不要修改返回视图。
- `digest(data)`：对上述内容做保持旧格式的规范 JSON SHA-256；来源、版本号和历史不属于此内容哈希。不应将它当成整个文件哈希、身份认证或用户同意证明。
- `edit(data, expected_revision, expected_content_sha256, operations, source)`：校验当前版本和内容哈希，原子地返回完整新资料。原输入对象不修改。
- `inspect(data, mode=None)`：返回普通/组合资料检查、缺失事实清单及最多两个后续问题。省略模式时，存在 combination 字段即为组合检查；可明确选择 ordinary 或 combo。它永不返回计算结果，charged 和 analysis_returned 均为 false。
- `IntakeError.issue` 提供结构化路径、代码、问题及类别。其他语法/边界错误可能是 ValueError。调用者须按输入错误处理，不能当成已完成计算。

按文件位置动态加载时，需要先把新模块注册到 `sys.modules` 再执行 `exec_module`，以支持 dataclasses。模块名可以由宿主选择；不要从玩家给定路径导入代码。

## 保留的事实与防错行为

- 未提供、null、明确 unknown、空列表/空对象保持原样；未知报价不变成零，空标签列表不自动成为已确认事实。
- 顶层和嵌套未知字段均拒绝；中性文件不能夹带账单、凭据、许可状态或结果缓存。
- 货币使用整数或普通十进制字符串，保留原文本精度；拒绝浮点、布尔充数、指数、负数、超范围和超过六位小数。JSON 节点、深度、字符串字节及整数另有限额。
- 记录编号必须明确且不重复；改动用 `{ "id": "资料编号" }` 定位，不准用列表顺序、名称或猜测的实物身份。编号本身不可变；已有非空对象和记录列表不能整体替换。
- 标签、角色需求、物品身份、事实依据、费用、区服或币种变化会保守地撤销受影响的旧确认，并在同一修改历史中记录自动撤销。只有本次明确确认相应字段才能重新保留确认；不能由宿主自动添加确认。
- 首次补齐未知实物身份保留该观察记录原基线事实，但仍撤销过早确认的相关标签；改成另一已知身份会撤销相应库存/兼容/费用确认。
- 修改核实日期不能续期旧库存可用性：必须逐件明确重新核实，或明确改为 unknown。加载、保存、其他字段修改不会刷新日期或报价观察日期。
- v1 读取和复制保留原格式；首次明确编辑迁移为 v2，新增历史保留 previous_schema 和编辑前内容哈希，原来源及旧历史不重写。
- 输入版本/内容已改变、重叠修改、无效稳定编号或超出版本上限时整轮失败，不留下半次修改。

## 检查边界与付费衔接

资料能保存或检查通过，不代表所有事实已核实、库存今天仍可用、报价有效或存在可行分配。这里仅进行与原资料层相同的语法/缺失/引用/组合范围检查，严格日期、费用语义和计算仍由服务端重新执行。不会在公开客户端补出或降级实现私有算法。

编辑不直接接触付款。`remote_client.py` 负责所选付费准备状态的绑定和撤销：已经绑定准备状态时，旧确认必须按客户端流程失效；离线新资料可继续本地编辑。支付状态不写入中性资料。公开模块本身只返回事实和修改历史，不能成为已付授权证明。
