# 自游·梦幻助手

用于梦幻西游电脑版时间服的 AI 助手 Skill。直接说出问题，就能核算花费、比较装备与养成路线、安排预算，并保存资料继续调整。支持能加载 Agent Skills 并执行 Python 的聊天助手。

## 能做什么

- 规则问答：说明有依据的玩法与材料规则，保留未知条件。
- 花费计算：计算修炼、宝石等养成所需材料和银两。
- 方案比较：比较装备、自升与买成品，以及不同预算下的选择。
- 资料管理：保存、补充和修改资料，继续调整原方案。
- 高级分析：按需选择跨情景共同方案、已有资产自动分配、角色套装与特技标记组合。

原有基础功能免费。三个高级服务按次收费，当前每次 1 元；资料保存、补充、修改和收费前准备免费。聊天助手的模型和服务可能另行收费。

## 安装

从 [Releases](https://github.com/mintzhao/ziyou-mhxy-assistant-skill/releases/latest) 下载 ZIP，解压后将完整 `ziyou-mhxy-assistant-paid` 文件夹安装到当前助手的 Skill 目录，或通过其导入功能加载。不要只复制 SKILL.md，也不要单独注册 basic 子目录。

也可以克隆源码后复制 [完整技能目录](skills/ziyou-mhxy-assistant-paid/SKILL.md)：

```powershell
git clone https://github.com/mintzhao/ziyou-mhxy-assistant-skill.git
```

运行计算需要 Python 3.10+，只依赖标准库。远程准备需要 HTTPS 访问；图片读取、文件保存和工具调用由当前助手提供。Codex、Claude Code、WorkBuddy 等宿主的安装方式见 [跨 agent 接入](docs/COMPATIBILITY.md)。

## 直接这样问

- “攻击修炼从 10 到 15，要准备多少钱和资材？”
- “这件装备自己打宝石，还是换成品更划算？”
- “按 800 万和 1000 万两个预算，分别比较这些装备。”
- “保存这份资料，下次接着改。”
- “我想把已有装备跨角色分配，先给我看分析范围和费用。”

普通使用无需写代码或填写 JSON。已知等级、预算和报价直接说，也可以附截图；缺少影响判断的信息时，助手会补问。

## 收费和隐私

高级服务先免费核对资料，展示完整摘要、费用和有效期。你明确确认后才生成账单，付款由独立的支付宝官方工具处理，并需要单独授权。安装支付工具不代表同意付款。

远程准备会把本次分析所需资料发给配置的服务端。不要上传游戏密码、验证码、钱包凭据或无关个人信息。技能不登录游戏、不替你买卖，也不自动获取实时区价。
