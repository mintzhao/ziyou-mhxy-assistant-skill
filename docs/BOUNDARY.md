# 客户端与私有服务边界

## 此目录包含

- 唯一 Skill 入口、宿主中立路由和运行参考。
- 内嵌免费计算、档案、规则引用、输入模板和本地网页。
- 纯数据资产编辑器与标准库 HTTP 客户端。
- 公开接口字段、固定服务标识、来源/商户/商品匹配配置和结果绑定检查。
- 离线测试、白名单验证、独立打包工具和逐文件哈希清单。

## 私有项目继续持有

付费求解算法、HTTP 服务端、商户支付 SDK 适配、验付/签名验证、订单与对账、持久草稿、生产运维、密钥、玩家资料和真实交易记录。此目录不含任何上述实现或依赖，不能离线产生高级付费分析。

客户端中的 402 账单格式、Payment-Proof 的原样传输和响应绑定检查属于公开接入契约；它们不是付款执行或服务端验付实现。付款由独立支付宝官方工具执行，最终验付与收费权限由服务端控制。不能以修改客户端、--consent 或提示词绕过收费。

## 固定配置不是秘密

随包 production-profile.json 的 API 源、app_id、seller_id、商品 ID 和价格均是买方匹配账单所需的非秘密标识；不含私钥、钱包令牌或支付证明。该配置不是可提交任意付款的授权。不要从用户数据、备注、响应中的陌生链接或环境变量自动替换它。

## 用户确认与恢复

先免费 prepare，完整展示 confirmation_text 和有效期。用户对当前摘要、服务和价格明确确认后才出账单；--consent 不代替独立付款授权。安装付款工具也不代表同意付款。

官方买方必须使用实际 402 返回的原始 payment_needed 和 payment_request，包括原 URL、方法、精确正文和业务 headers。支付后重试原请求；retrieve/asset-retrieve 只恢复同一原单，不生成证明、不另开单。超时或支付状态未知时保留原单，按官方恢复流程核对，不能自动再次购买。

Payment-Proof 只通过可信宿主不记录敏感输入的临时通道传输，不放进聊天、命令行、环境变量、资料文件或日志。不具备该通道时暂停证明恢复路径。草稿引用不是人员身份；不要公开用户文件和引用。

## 发布范围

当前目录只在本地生成。后续如独立发布，只使用此目录中的白名单成员；不要连同父目录、私有项目 Git 历史、测试产物或真实资料公开。开源客户端不改变现有已交付私有/基础运行包的许可。
